# Dashboards
A collection of interactive dashboards and data visualization projects created using Looker Studio (Data Studio), Power BI, and Lovable.
This repository showcases my ability to transform raw datasets into meaningful visual insights through dashboard creation, business
intelligence reporting, and data storytelling. 

The projects included in this repository demonstrate practical skills in:
- Dashboard design
- Data visualization
- KPI reporting
- Business analytics
- Interactive reporting
- Data storytelling
- User-focused dashboard development

### Purpose of the Repository

The purpose of this repository is to store and showcase dashboard projects created as part of my data analytics learning journey,
practical exercises, and portfolio development. These dashboards were built using different visualization platforms to analyze datasets
and communicate insights effectively.

### Objectives

The following activities were completed as part of the dashboard projects:
- Connecting and preparing datasets for visualization
- Cleaning and transforming data for reporting
- Building interactive dashboards and reports
- Creating charts, scorecards, and KPI visualizations
- Designing user-friendly dashboard layouts
- Analyzing trends and business performance
- Presenting insights using data storytelling techniques
- Organizing dashboard projects for portfolio purposes

### Tools Used

- Looker Studio (Data Studio) -	Interactive Dashboard Creation
- Power BI	- Business Intelligence Dashboards
- Lovable	- Dashboard & App Prototyping
- Microsoft Excel - Pivots and charts
- GitHub - Portfolio & Version Control
